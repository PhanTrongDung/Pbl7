# Project Documentation

## Overview
This project is a legal AI system for Vietnamese legal document retrieval, management, and analysis.

## Stack
- FastAPI
- SQLAlchemy
- MySQL
- React + Vite
- RAG pipeline
- LLM + embedding retrieval

## Modules
- Backend: legal AI APIs and data layer
- Frontend: dashboard and chat interface
- Data: legal documents and embeddings
- Docs: technical documentation
